Features
Responsive Design: The website is fully responsive, adapting to all screen sizes (mobile, tablet, and desktop).
Interactive UI: JavaScript adds interactive elements like smooth scrolling, animations, and dynamic content.
Showcase of Projects: Display of personal and professional projects with links to their live versions and GitHub repositories.
Contact Form: Integrated contact form that lets visitors send me messages directly.
Clean and Minimal UI: Modern design using CSS for styling.
Technologies Used
HTML5: Structure and semantic layout.
CSS3: Styling, Flexbox, and Grid for responsive design.
JavaScript: For interactive elements and dynamic content.
